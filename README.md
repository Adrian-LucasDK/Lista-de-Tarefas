# ✅ Lista de Tarefas (To-Do List)

Aplicativo desenvolvido em Python com interface gráfica utilizando Tkinter, que permite cadastrar, acompanhar, concluir e excluir tarefas de maneira simples e organizada.

## 🚀 Funcionalidades

- Adicionar novas tarefas.
- Listar atividades cadastradas.
- Marcar tarefas como concluídas.
- Identificar tarefas pendentes.
- Excluir tarefas selecionadas.
- Confirmação antes da exclusão.
- Interface gráfica intuitiva.
- Atualização dinâmica da lista de atividades.

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter

## 📋 Requisitos

- Python 3 instalado.
- Tkinter disponível na instalação do Python.

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd lista-de-tarefas
```

3. Execute o programa:

```bash
python tarefas.py
```

## 📚 Objetivo

Projeto desenvolvido para praticar lógica de programação, manipulação de listas e estruturas de dados, criação de funções e desenvolvimento de interfaces gráficas com Python.

## ⚠️ Observação

Nesta versão, as tarefas ficam armazenadas apenas durante a execução do programa. Ao fechar o aplicativo, os dados não são mantidos.
